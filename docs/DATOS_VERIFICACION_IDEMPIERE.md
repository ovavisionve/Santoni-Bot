## Notas Importantes

1. **m_production.productionqty es negativo** en iDempiere de Santoni — usar `m_productionline.movementqty` para cantidades reales
2. **pp_order está vacío** — Santoni no usa el módulo Manufacturing, usa m_production directamente
3. **Stock negativo** es normal para materias primas — refleja consumo acumulado
4. **Código 01-0** tiene 3 registros en m_product (2x ARROZ DE CONSUMO + 1x ARROZ PADDY ACONDICIONADO)
5. **Monedas USD** tienen múltiples iso_codes por organización (DOL, DoL, Dol, USA, dol, DLA, Dla, US.)
